## Enter the system

PROJECT ZERO is not a conventional portfolio page. It is a navigable personal operating system built around a dark, neon-green visual language:

- Boot into the experience through a terminal-inspired startup sequence.
- Explore a responsive digital identity file.
- Inspect a simulated network topology and send an educational packet.
- Switch between technical capability modules.
- Browse verified project repositories through an interactive archive.
- Travel through an academic timeline.
- Open a command-driven terminal and explore the portfolio without a mouse.
- Reach out through a validated contact form and direct social links.

The experience is designed to make a recruiter curious first, then make the underlying qualifications easy to understand.

## Live preview

### Local preview

The project has been built and browser-smoke-tested locally. To launch the live preview:

```bash
npm install
npm run build
npm run preview
```

Then open **[http://localhost:4173](http://localhost:4173)**.

> This repository currently has no configured Git remote or hosting credentials, so a public URL cannot be claimed honestly yet. The app is deployment-ready; connect the repository to Vercel, Netlify, or GitHub Pages to publish it.

### Recommended public deployment

#### Vercel

1. Import the repository at [vercel.com/new](https://vercel.com/new).
2. Keep the detected framework as **Vite**.
3. Use `npm run build` as the build command.
4. Use `dist` as the output directory.
5. Deploy.

#### Netlify

1. Import the repository at [app.netlify.com](https://app.netlify.com/).
2. Build command: `npm run build`
3. Publish directory: `dist`
4. Deploy the site.

## Terminal commands

Open **TERMINAL** from the navigation and try:

```text
help       List available commands
whoami     View the digital identity
about      Read the short profile
skills     List technical areas
projects   List featured projects
education  View the education path
github     Open the GitHub profile
contact    View the email address
clear      Clear terminal output
matrix     Engage the visual matrix layer
exit       Close the terminal
```

The terminal is a safe frontend simulation. It never executes operating-system commands or accesses visitor devices.

## Accessibility and performance

- Reduced-motion preferences disable the continuous matrix animation and shorten motion effects.
- All primary interactions have keyboard-accessible button controls.
- Mobile navigation replaces the desktop navigation instead of simply shrinking it.
- The network is an educational visualization, not a real scanner.
- The contact form reports its unconfigured delivery state instead of showing a false success.
- Canvas rendering caps device pixel ratio to keep the background affordable.
- The CV is intentionally separate from the cinematic visual system and remains print-friendly.
